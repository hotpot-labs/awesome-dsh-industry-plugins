# EarthPretender/dsh-session-delete

- **仓库地址**: https://github.com/EarthPretender/dsh-session-delete
- **收录分类**: 其他
- **插件简介**: 在侧栏会话“…”菜单的“归档会话”下方新增红色“删除会话”行，永久删除该会话的日志与工作区账目（走 workspace registry 自己的持久化写）。第二次点击确认后该行立即从列表消失；当次启动使用过的会话会先从内存停用再删（不会复活）；正在跑任务的会话会再显示一次警告，点下去先停止任务再删除。
