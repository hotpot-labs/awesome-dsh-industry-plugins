# GoldenLoaf24h/dsh-prompt-suggestion

- **仓库地址**: https://github.com/GoldenLoaf24h/dsh-prompt-suggestion
- **收录分类**: 其他
- **插件简介**: 每轮结束后预测你的下一句话，以灰色 ghost text 显示在输入框：Tab 整条采纳、Alt+→ 逐词采纳、Enter 采纳并发送、Esc 忽略、Alt+R 换一条且不重复旧的那条；输入几个字时用本会话发过的提示做前缀补全，空输入框按 ↑ 回填上一条；插件页可设置服务商、模型、思考强度、各按键开关与生成参数。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-22
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
