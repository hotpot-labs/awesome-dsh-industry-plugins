# Apauto-to-all/dsh-hindsight-control-plane

- **仓库地址**: https://github.com/Apauto-to-all/dsh-hindsight-control-plane
- **收录分类**: 其他
- **插件简介**: 把 Hindsight 记忆控制台嵌进 DSH 主面板：侧栏一键打开整块控制台，由 npx 拉起、随插件起停。它的 HTTP 路由没有 DSH 的访问检查，浏览器里打开的网页可以调用它们。它通过 npx 启动 Hindsight 控制台（默认版本是 latest），控制台默认监听 0.0.0.0:9999，不设置主机名时整个局域网都能访问。
