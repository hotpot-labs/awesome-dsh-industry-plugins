# FelixJiashengFu/dsh-force-collab

- **仓库地址**: https://github.com/FelixJiashengFu/dsh-force-collab
- **收录分类**: 其他
- **插件简介**: 强制协作：在输入框左侧选 0–6 个子 Agent，开启后每个动手的任务都必须通过没有数量参数的 collab_fanout 工具拆给正好这么多个子 Agent 并行，再由主 Agent 汇总。
