# CG-7S/dsh-waitiforud

- **仓库地址**: https://github.com/CG-7S/dsh-waitiforud
- **收录分类**: 其他
- **插件简介**: 在一个文件夹里执行过任务后，开始下一个任务时模型仍会查看该文件夹内的内容，可能造成上下文混乱、思考量过多、额外消耗 token 等；本插件在每次完成任务后生成一个新的空文件夹并置顶在工作区等待调用，原文件夹会根据任务内容命名，全程在本地执行，安全可靠。
