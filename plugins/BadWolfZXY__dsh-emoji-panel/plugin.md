# BadWolfZXY/dsh-emoji-panel

- **仓库地址**: https://github.com/BadWolfZXY/dsh-emoji-panel
- **收录分类**: 其他
- **插件简介**: DSH 输入框里的表情面板：分类标签 + 常驻搜索框，200 多个 Unicode emoji，另有「最近」和「自定义」——自定义可导入本地图片或图片网址，导入时写一句含义。点选即插到光标处、自动收起并把焦点还给输入框；导入的表情插入「[表情: 含义]」文本，模型据此理解表情意思。数据只存本机浏览器。
