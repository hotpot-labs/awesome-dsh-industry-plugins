# Dcmwfg/dsh-deepseek-sidebar

- **仓库地址**: https://github.com/Dcmwfg/dsh-deepseek-sidebar
- **收录分类**: 其他
- **插件简介**: 左侧栏一行把 chat.deepseek.com 开进右侧栏标签页，不影响当前对话，可随时全屏；与侧边栏浏览器共用同一 cookie 分区，附带脚本让登录跨重启保留。仅限桌面版（Electron）；跨重启保留登录需运行自带的 PowerShell 补丁，该补丁仅支持 Windows，且每次升级 DSH 后都要重跑。
