# zhengjy01/dsh-cubox

- **仓库地址**: https://github.com/zhengjy01/dsh-cubox
- **收录分类**: 其他
- **插件简介**: Cubox 收藏同步：定时同步收藏，按你的 prompt 用 LLM 生成今日收藏简报直接写入 Obsidian，可导出每张收藏为 Markdown。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-09-01
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
