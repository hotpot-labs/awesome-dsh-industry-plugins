# Duanyy0813/dsh-prompt-clarifier

- **仓库地址**: https://github.com/Duanyy0813/dsh-prompt-clarifier
- **收录分类**: 其他
- **插件简介**: 在 DSH 输入框添加「提示词优化」按钮；开启自动模式后，在助手开始执行前先用旁路模型结合最近会话上下文改写提示词，无法确定改写方式时先用原生提问卡片确认，各阶段以命令卡片在主对话中播报，分析失败时按原文继续。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-03
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
