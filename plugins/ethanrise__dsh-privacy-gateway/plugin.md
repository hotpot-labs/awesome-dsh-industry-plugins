# ethanrise/dsh-privacy-gateway

- **仓库地址**: https://github.com/ethanrise/dsh-privacy-gateway
- **收录分类**: 其他
- **插件简介**: 在对话消息发给模型前，把个人信息替换为占位符（按上下文识别的中文姓名、大陆手机号与身份证号、邮箱、银行卡号，以及用户词库中的词），原文只在本机界面还原显示；并可生成 CSV/XLSX 的脱敏副本。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-15
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
