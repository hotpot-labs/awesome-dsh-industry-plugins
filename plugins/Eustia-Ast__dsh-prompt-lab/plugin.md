# Eustia-Ast/dsh-prompt-lab

- **仓库地址**: https://github.com/Eustia-Ast/dsh-prompt-lab
- **收录分类**: 其他
- **插件简介**: 按会话改写、置空或新增 DeepSeek Harness 系统提示词 section，支持模板、预设、自动备份、空白窗口草稿、追加消息与按会话的 global 工具开关；只影响用户明确开启的会话。它的 HTTP 路由没有 DSH 的访问检查，浏览器里打开的网页可以调用它们。
