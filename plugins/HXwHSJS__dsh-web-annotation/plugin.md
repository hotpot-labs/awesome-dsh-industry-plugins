# HXwHSJS/dsh-web-annotation

- **仓库地址**: https://github.com/HXwHSJS/dsh-web-annotation
- **收录分类**: 其他
- **插件简介**: 在 DSH 右侧边栏 Browser 中批注元素、空白位置或框选区域；每批保存截图与报告文件，并以文本形式附加到下一条消息。不替换官方 Browser、Chat 或 Layout 提供方。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-29
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
