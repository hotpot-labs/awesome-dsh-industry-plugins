# RyanZeeee/dsh-chattree

- **仓库地址**: https://github.com/RyanZeeee/dsh-chattree
- **收录分类**: 其他
- **插件简介**: 把 DSH 会话画成一张对话画布：每轮问答是一个节点，任意节点都能分叉出真实的子会话，压缩过的上下文收成一个绿色节点、可以从它继续对话；左侧栏按 DSH 工作区分组列出画布，重命名与 DSH 自己的会话标题同步。

- **审核日期**: 2026-09-18
- **审核定级**: 🔴 黑名单 (禁止使用)
