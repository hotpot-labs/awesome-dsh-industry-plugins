# HonestShine/dsh-desktop-notify

- **仓库地址**: https://github.com/HonestShine/dsh-desktop-notify
- **收录分类**: 其他
- **插件简介**: DSH 的原生桌面通知。窗口在后台时权限确认直接出现在系统通知里；平台支持通知按钮时，点「拒绝 / 允许一次」即把结果交回宿主审批流程，切回窗口或超时则退回应用内审批面板。权限确认与提问还会播放独立于窗口焦点的交互提示音；任务完成、提问、错误提醒、通知铃声与提示音都在「通知提醒」设置页配置。
