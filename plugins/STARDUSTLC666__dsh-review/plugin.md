# STARDUSTLC666/dsh-review

- **仓库地址**: https://github.com/STARDUSTLC666/dsh-review
- **收录分类**: 其他
- **插件简介**: 绑定代码快照的多智能体 Git 审阅，支持独立复核、多数投票、问题处置追踪和 AI 审阅门禁。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-26
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
