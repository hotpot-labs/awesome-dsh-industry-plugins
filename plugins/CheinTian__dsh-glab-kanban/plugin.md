# CheinTian/dsh-glab-kanban

- **仓库地址**: https://github.com/CheinTian/dsh-glab-kanban
- **收录分类**: 其他
- **插件简介**: 基于 glab 命令行的 GitLab Issue 看板：项目 Issue 看板的每个标签列变成一列，拖拽卡片即切换状态标签。提供侧边栏面板（项目选择、筛选、卡片详情抽屉：Markdown 描述、评论与动态、评论、关闭、重开），以及按工作区 origin 远程自动绑定项目的会话视图标签页，并通过同一个 glab_kanban 工具让 Agent 执行相同操作。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-15
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
