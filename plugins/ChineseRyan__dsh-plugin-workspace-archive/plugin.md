# ChineseRyan/dsh-plugin-workspace-archive

- **仓库地址**: https://github.com/ChineseRyan/dsh-plugin-workspace-archive
- **收录分类**: 其他
- **插件简介**: 在工作区行菜单里加一项「归档工作区」：对该工作区下每个会话调用官方归档命令，当前正在查看的那条保持打开；组内有会话仍在运行时整批拒绝。官方会隐藏已归档的会话，却把清空后的工作区行留在侧栏——本插件把这一行也一并收起，并从底部面板按 $DSH_HOME/storages 里带跨进程锁写入的账本整组恢复。数量角标可设为常驻、仅新归档时、或隐藏。
