# Jason25417/dsh-session-auto-rename

- **仓库地址**: https://github.com/Jason25417/dsh-session-auto-rename

- **插件简介**: 在每个会话的侧栏菜单里新增「自动重命名」：模型读取会话日志，按时间衰减给用户消息加权（τ = 3 天，越新权重越高），写出不超过 10 个汉字的标题并写入会话名。同时支持右键会话呼出该菜单，并把同一操作暴露为 session_auto_rename 智能体工具。需要 DSH 0.2.1-rc.5 或更新版本。
