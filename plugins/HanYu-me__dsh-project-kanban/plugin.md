# HanYu-me/dsh-project-kanban

- **仓库地址**: https://github.com/HanYu-me/dsh-project-kanban
- **收录分类**: 其他
- **插件简介**: dsh 侧边栏里的项目看板。每个项目一个区块，固定四列（待办 / 进行中 / 待反馈 / 已完成）：新建、重命名、换色、排序、删除项目和任务，点一下把任务推到下一列，拖拽或卡片菜单调整顺序，删除可撤销，项目可折叠。颜色、圆角和阴影取自 dsh 主题变量，跟随浅色/深色，宽度不够时从四列变两列再变单列。
