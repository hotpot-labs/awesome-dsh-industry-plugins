# Edsenpai/page-between

- **仓库地址**: https://github.com/Edsenpai/page-between
- **收录分类**: 其他
- **插件简介**: 贴一个链接，把文章读成结构导图、加粗要点、逐段精读与读后评论；任意一句可收成拍立得便签（可拖动、缩放、改字），全文可一键复制成 Notion 版，简/繁/英三种语言可随时切换。导图图片依赖本机 Edge/Chrome，仅 Windows 自动识别（其他系统需设置环境变量 DSH_MINDMAP_BROWSER），不影响其余功能。
- **收录来源**: awesome-dsh-plugin

- **审核定级**: 🔴 黑名单 (禁止使用)
