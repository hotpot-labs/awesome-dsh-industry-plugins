# Eclipse-NotFound/dsh-incident-studio

- **仓库地址**: https://github.com/Eclipse-NotFound/dsh-incident-studio
- **收录分类**: 计算机
- **插件简介**: 把屏幕画面、日志和（Windows 上）键鼠输入放在同一条毫秒时间轴上：录完标出问题区间、在画面上拖框标注，再把关键帧条带、动图和对齐后的日志切片连同描述一起交给 Agent。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-07
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
