# JauLukNgai/dsh-on-phone

- **仓库地址**: https://github.com/JauLukNgai/dsh-on-phone

- **插件简介**: 让手机浏览器直接使用电脑上的 DSH 网页界面，远程通道建立在 Tailscale Serve 之上。两边除了 Tailscale 不用再装任何东西：没有专用 App、没有二维码、没有登录页，插件不设账号，也不中转你的内容。电脑端支持 macOS、Windows 与 Linux。
