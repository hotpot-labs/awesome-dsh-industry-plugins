# AL-Yichen/dsh-fullscreen-input

- **仓库地址**: https://github.com/AL-Yichen/dsh-fullscreen-input
- **收录分类**: 其他
- **插件简介**: 给 DSH 的输入框加一个全屏输入面板，用于书写多行文本，可移动、可调整大小，与主输入框共用同一份草稿；Enter 只换行、仅 Ctrl+Enter 发送，因此中文输入法不会把 Shift+Enter 变成发送。
