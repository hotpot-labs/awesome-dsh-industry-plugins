# 1687210989/agent-clinic

- **仓库地址**: https://github.com/1687210989/agent-clinic
- **收录分类**: 其他
- **插件简介**: DSH 会话日志的只读体检诊所：22 项具名诊断（token 浪费、重试与失败循环、上下文膨胀、跨会话失忆、闲置的 MCP 服务器与 skill 等），每条都附可复核的证据定位符（如 session.v4.jsonl.zstd#L101-L110）；每个问题给一条可执行处方（profile patch 片段或命令，含当前值到建议值、风险与验证方式），并支持标记「已拒绝」让该处方不再出现（报告会写明是你撤掉的）。零依赖、默认零外发、会话文件只读。
- **收录来源**: awesome-dsh-plugin

- **审核定级**: 🔴 黑名单 (禁止使用)
