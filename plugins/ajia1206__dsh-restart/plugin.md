# ajia1206/dsh-restart

- **仓库地址**: https://github.com/ajia1206/dsh-restart
- **收录分类**: 计算机
- **插件简介**: 用模型工具或右下角 GUI 控件重启正在运行的 DSH 进程：探测 launchd KeepAlive，无托管时派 detached supervisor 兜底（握手失败即取消退出），桌面版走 macOS 应用重启路径，每次重启写入按 armId、pid 与 profile 关联的 JSONL 记录，使一次重启能与日志里的无关活动区分开。
