# Elefseus/dsh-pet-progress

- **仓库地址**: https://github.com/Elefseus/dsh-pet-progress
- **收录分类**: 其他
- **插件简介**: 把 dsh 宠物忽略的 todo 与 goal 事件折成宠物气泡上的百分比进度；会话没有任务列表时退化为一行当前活动摘要。需先安装 dsh web pet 插件（@linxin666/dsh-pet >= 0.4.0）。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-21
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
