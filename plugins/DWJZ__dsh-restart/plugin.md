# DWJZ/dsh-restart

- **仓库地址**: https://github.com/DWJZ/dsh-restart
- **收录分类**: 其他
- **插件简介**: 在 DSH Web 设置面板里增加一个「重启」页：显示当前宿主的 PID、端口、启动时间与运行时长，重启由分离的 helper 完成——等端口不再应答后再按同一启动命令拉起新进程；替代宿主返回新的 boot id 后页面自动刷新。
