# JupiterWalker/dsh-section

- **仓库地址**: https://github.com/JupiterWalker/dsh-section
- **收录分类**: 其他
- **插件简介**: 把不同项目的会话收进左侧边栏里可折叠的自定义分组：会话行与项目行各有菜单，可加入分组、移出分组、重命名、归档，或把整个项目一次性移入某个分组；分组面板里的开关可把宿主侧栏切换成分组树、随时恢复，行尾还会提示会话正在跑或跑完还没看过。
