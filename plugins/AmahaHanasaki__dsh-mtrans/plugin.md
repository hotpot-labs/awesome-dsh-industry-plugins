# AmahaHanasaki/dsh-mtrans

- **仓库地址**: https://github.com/AmahaHanasaki/dsh-mtrans
- **收录分类**: 其他
- **插件简介**: 四个 DSH 工具，用于翻译 MTool 格式的游戏文本：mtrans_info 分析 ManualTransFile.json，mtrans_prepare 把文本键拆成块文件，mtrans_apply 合并译文回写，mtrans_translate 通过已注册的大模型服务整篇翻译（日译中或英译中）。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-20
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
