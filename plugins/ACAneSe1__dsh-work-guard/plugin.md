# ACAneSe1/dsh-work-guard

- **仓库地址**: https://github.com/ACAneSe1/dsh-work-guard
- **收录分类**: 其他
- **插件简介**: 给编程 agent 的闸门与台账：没读过的源码文件拒绝写入，读过之后又被改动的也拒绝；每次写入与验证都记下真实退出码；修之前红着的那批测试，在它们真正变绿之前会一直显示出来；脚本改了源码却没申报会一直记在台账里。它的 HTTP 路由没有 DSH 的访问检查，浏览器里打开的网页可以调用它们。
- **收录来源**: awesome-dsh-plugin

- **审核定级**: 🔴 黑名单 (禁止使用)
