# 329604421/dsh-agent-todo

- **仓库地址**: https://github.com/329604421/dsh-agent-todo
- **收录分类**: 其他
- **插件简介**: 把多项目待办工作台装进 DSH：全局胶囊浮层随手记想法，归到项目、拆成脑图，再把待办一键导出到输入框交给 Agent。登录后，笔记与待办的读写都发生在作者托管的服务（todo.memorymap.cn）上；可用 config.apiBase 改指向你自己的后端。它的 HTTP 路由没有 DSH 的访问检查。
