# AshenSeeker/dsh-subagent-switch

- **仓库地址**: https://github.com/AshenSeeker/dsh-subagent-switch
- **收录分类**: 其他
- **插件简介**: 未由调用方指定模型时，按任务类型从本机模型目录为每个子代理挑一个模型。免费与额度档合并后按逐模型能力标签排序；只有当便宜档里没有任何模型声明擅长这类工作时，才升到更贵的档。只有余额可读或账号接入的 provider 进候选池，其余仍列出但不参与路由。面板提供盖过自动顺序的逐模型手动优先级，以及放行/收回开关。
