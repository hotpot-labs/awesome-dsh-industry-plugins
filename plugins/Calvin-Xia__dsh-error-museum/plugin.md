# Calvin-Xia/dsh-error-museum

- **仓库地址**: https://github.com/Calvin-Xia/dsh-error-museum
- **收录分类**: 其他
- **插件简介**: 把最近 30 天（可切 7 / 30 / 90 天）的会话可确认失败做成「错误博物馆」，展品按模型失败后的处置（复原 / 重试 / 交还 / 搁置）分馆陈列，保留失败前后的调用与错误原文。会话日志只在本机读取，只有点「用模型深挖」时才把该会话摘要发给已配置的模型。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-25
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
