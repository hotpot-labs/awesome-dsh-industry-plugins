# SOVLOOKUP/dsh-cloud-download

- **仓库地址**: https://github.com/SOVLOOKUP/dsh-cloud-download
- **收录分类**: 其他
- **插件简介**: 在交付卡片、变更审查和文档预览上增加下载按钮，并隐藏 Host 远程或无桌面时无法生效的原生打开控件。需 DSH Web；原生打开控件默认隐藏，可在浏览器里恢复。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-26
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
