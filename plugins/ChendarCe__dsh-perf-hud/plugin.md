# ChendarCe/dsh-perf-hud

- **仓库地址**: https://github.com/ChendarCe/dsh-perf-hud
- **收录分类**: 其他
- **插件简介**: DSH 界面上的透明性能悬浮窗：三行小字直接浮在界面上显示 CPU、GPU、内存占用率，没有底色也没有边框，可拖动并吸附到最近的窗口角，最大化或改变窗口大小都不会跑位；CPU 封装温度由可选的高权限助手（LibreHardwareMonitor + PawnIO）读取，插件自身开销不到单核百分之一。仅 Windows。
