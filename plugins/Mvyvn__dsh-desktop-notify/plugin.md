# Mvyvn/dsh-desktop-notify

- **仓库地址**: https://github.com/Mvyvn/dsh-desktop-notify
- **收录分类**: 其他
- **插件简介**: 为 11 类可配置的 DSH agent 事件（任务完成、提问、审批被拒、后台子代理/目标/任务、团队任务、上下文压缩、定时任务触发、插件挂载、权限变更）发送桌面通知，优先走自带 Service Worker 的浏览器 Web Notification，降级到 Windows Toast 或 Linux D-Bus，支持三档静默与点击跳转。
