# WsTe47/dsh-step-clock

- **仓库地址**: https://github.com/WsTe47/dsh-step-clock
- **收录分类**: 其他
- **插件简介**: 在网页版输入框上方用一句中文显示当前正在执行的智能体步骤：步号、正在执行的工具、以及已运行多久。步骤结束后会保留该步用时，直到下一步开始，因此慢步骤事后也能查证。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-09-18
- **审核定级**: 🔴 黑名单 (禁止使用)
