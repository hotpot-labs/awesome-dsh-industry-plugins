# lumoping/dsh-todo-inbox

- **仓库地址**: https://github.com/lumoping/dsh-todo-inbox
- **收录分类**: 其他
- **插件简介**: DSH Web 全局跨会话待办收件箱：任意会话的 agent 通过 inbox_add/inbox_done/inbox_list 登记等待人类处理的事项（合并 MR、审批工单、评审等）；侧边栏入口显示未完成数角标与可展开的待办列表，支持打开与完成，数据持久化到 ~/.dsh/todo-inbox.json。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-09-09
