# PerryLink/dsh-reach

- **仓库地址**: https://github.com/PerryLink/dsh-reach
- **收录分类**: 其他
- **插件简介**: 把 DSH 的审批卡与提问卡推送到 IM 渠道（先支持微信），可在聊天里直接作答，带会话控制台、逐渠道安全与开放推送服务。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-09-05
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
