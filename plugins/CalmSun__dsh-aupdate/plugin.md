# CalmSun/dsh-aupdate

- **仓库地址**: https://github.com/CalmSun/dsh-aupdate
- **收录分类**: 其他
- **插件简介**: 定时检查 DSH 已装插件的 npm 新版本，逐个安装并就地生效，不用重启；每次安装前留快照，可按包回滚，某个版本失败后一段时间内不再重试，带跨进程锁和更新提醒；设置页中英双语、改动即存，并自动清理超过保留期的更新记录与运行日志（默认 3 天）。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-25
- **审核定级**: 🔴 黑名单 (禁止使用)
