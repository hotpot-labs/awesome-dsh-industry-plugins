# BigBugy/dsh-tool-session-message

- **仓库地址**: https://github.com/BigBugy/dsh-tool-session-message
- **收录分类**: 其他
- **插件简介**: 跨会话发消息：按 session id 把 user 消息投递到另一个 DSH 会话，消息自动附带发送方 Session ID 与回信提示，方便多窗口互相认证与接续任务。单一工具、不依赖额外的 DSH 包；mode 取 "steer" 时插入正在运行的一轮，而不是排队成新一轮。
