# CodeIntegrity/dsh-semble

- **仓库地址**: https://github.com/CodeIntegrity/dsh-semble
- **收录分类**: 其他
- **插件简介**: 面向 DeepSeek Harness 的语义代码搜索：注册 semble_search（按行为描述检索代码，返回按相关度排序的 file:line 命中）与 semble_find_related（查找已知位置的相邻代码）两个原生工具，检索由 uvx 启动的 Semble CLI 完成，并附一个随包分发的路由技能。需要 PATH 中有 uv；对某个仓库的首次查询会建立索引。
