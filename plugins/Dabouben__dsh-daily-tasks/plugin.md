# Dabouben/dsh-daily-tasks

- **仓库地址**: https://github.com/Dabouben/dsh-daily-tasks
- **收录分类**: 其他
- **插件简介**: 每日/每周任务管理：启动弹窗提醒、输入框上方滚动条、圆圈一键完成、任务卡片编辑、周日 AI 周总结；另附侧边栏 DeepSeek API 用量小部件（余额卡片、今日与累计 tokens 及费用、按模型明细、近 7 日柱状图）。数据以 JSON 存于 $DSH_HOME。
