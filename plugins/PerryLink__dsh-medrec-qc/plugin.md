# PerryLink/dsh-medrec-qc

- **仓库地址**: https://github.com/PerryLink/dsh-medrec-qc
- **收录分类**: 其他
- **插件简介**: 依据国卫办医发〔2016〕24号等公开文件，核对病案首页各字段的齐备性与字段间的逻辑矛盾。列出缺失或不一致之处供人复核，不评价临床正确性。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-21
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
