# BearingSteel/dsh-inline-download

- **仓库地址**: https://github.com/BearingSteel/dsh-inline-download
- **收录分类**: 其他
- **插件简介**: 在用户消息里的上传文件气泡上添加下载按钮，同时覆盖 present 交付卡片，把原始文件流式下载到浏览器；附件下载通过会话日志与鉴权坐标定位文件，URL 中不携带路径。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-16
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
