# LinXueyuanStdio/dsh-git

- **仓库地址**: https://github.com/LinXueyuanStdio/dsh-git
- **收录分类**: 其他
- **插件简介**: DSH 官方右侧栏里的本地 Git 与四个 GitHub 远端页签：Changes（按文件暂存、逐行 diff、提交信息由 DSH 里已配好的模型生成）、History，以及由 host 半代理的 Code / Issues / Pull requests / Actions。令牌只存在 host 半（ctx.credentials），/dsh-git/* 只接受 loopback 请求。
