# magicOF2/dsh-schedule

- **仓库地址**: https://github.com/magicOF2/dsh-schedule
- **收录分类**: 其他
- **插件简介**: 本地长期日程面板:顶栏「日程」文字按钮、今天/本周/历史月历统计视图、完成打勾(按天记录历史)、日程↔会话链接点击跳转、重复日程(每天/每周)、一次性日程可选未完成自动顺延,以及 dailytask_* agent 工具。

- **审核日期**: 2026-08-27
- **审核定级**: 🔴 黑名单 (禁止使用)
