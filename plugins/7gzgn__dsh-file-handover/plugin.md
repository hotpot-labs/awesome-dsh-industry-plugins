# 7gzgn/dsh-file-handover

- **仓库地址**: https://github.com/7gzgn/dsh-file-handover
- **收录分类**: 其他
- **插件简介**: 把本地文件交给任何程序的「打开文件」对话框：等对话框出现、走剪贴板填路径、读回来逐字核对、再点确认。目标必须显式给，每一步都留证据——文件上传、微信发文件、PS 打开都能用它代劳。仅 Windows（依赖 EnumWindows / UI Automation）。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-19
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
