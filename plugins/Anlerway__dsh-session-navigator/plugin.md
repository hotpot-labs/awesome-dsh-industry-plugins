# Anlerway/dsh-session-navigator

- **仓库地址**: https://github.com/Anlerway/dsh-session-navigator
- **收录分类**: 其他
- **插件简介**: 像 Windows 资源管理器那样管理 DSH 的会话：目录树、标签、备注、回收站。文件夹、标签、备注存在独立索引里；删除会话会把其目录移入插件回收站，跨工作区剪切会移动会话文件并改写其 cwd。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-25
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
