# Hmuer/dsh-deepseek-wallet

- **仓库地址**: https://github.com/Hmuer/dsh-deepseek-wallet
- **收录分类**: 其他
- **插件简介**: 在输入框工具栏实时显示 DeepSeek 账户余额，并在每轮完成对话的 token 用量旁显示按官方峰谷价计费的人民币金额：北京时间工作日上下午为高峰价，周末与法定节假日为空闲价。余额需要 DEEPSEEK_API_KEY 凭据，仅通过 DeepSeek OAuth 登录的账号不显示余额。
