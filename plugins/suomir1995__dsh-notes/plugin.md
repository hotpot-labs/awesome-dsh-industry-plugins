# suomir1995/dsh-notes

- **仓库地址**: https://github.com/suomir1995/dsh-notes
- **收录分类**: 其他
- **插件简介**: 把笔记存成你选定根目录下按分组组织的本地 Markdown 文件，带侧栏页面，并把 AGENTS 等规则 md 作为写作上下文，另有六个 agent 工具。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-09-15
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
