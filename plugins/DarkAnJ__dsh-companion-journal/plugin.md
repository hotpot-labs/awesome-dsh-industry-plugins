# DarkAnJ/dsh-companion-journal

- **仓库地址**: https://github.com/DarkAnJ/dsh-companion-journal
- **收录分类**: 其他
- **插件简介**: 自带桌宠的 macOS 感知层：六个 companion_* 工具读取前台窗口、截图给模型看、用气泡说话，并把看到的内容留在本机陪伴记录里。仅支持 macOS 11+。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-11
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
