# RaditPasya/dsh-web-git-sidebar

- **仓库地址**: https://github.com/RaditPasya/dsh-web-git-sidebar
- **收录分类**: 其他
- **插件简介**: DSH Web 左侧栏的源代码管理面板：搜索、切换与创建分支并显示领先/落后提交数，拓扑序提交图，点击任意提交可展开查看其文件（A/M/D）、增删行数、提交信息、作者与时间。设置上方常驻一个底部停靠区，包含分支下拉与最近提交并跟随当前会话；fetch 与快进 pull 合并为一个按钮；另有 git_worktree 工具供智能体创建、列出与移除 worktree。
