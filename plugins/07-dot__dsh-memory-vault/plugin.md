# 07-dot/dsh-memory-vault

- **仓库地址**: https://github.com/07-dot/dsh-memory-vault
- **收录分类**: 其他
- **插件简介**: 把 Obsidian Markdown 记忆库接进 Harness：每个 Agent 创建时挂一个提示词上下文，按当前任务文本检索后注入常驻档案与相关条目；另有三个工具用于读写与结构体检（收件箱积压、断链、重复候选、过期目标）。检索为本地 n-gram 打分，无嵌入模型、无外部服务、无运行时依赖。
