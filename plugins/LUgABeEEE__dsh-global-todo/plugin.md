# LUgABeEEE/dsh-global-todo

- **仓库地址**: https://github.com/LUgABeEEE/dsh-global-todo
- **收录分类**: 其他
- **插件简介**: 侧边栏里的全局跨会话待办清单，人和 agent 共用同一份：十个 global_todo_* 工具可在任意会话中新增、批量抓取、修改、挂文档与链接、追加进展记录、标记完成；每条待办可按四种方式交给 agent 会话，派发结果记回条目本身。清单存成一个 JSON 文件。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-21
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
