# Fucaplos/dsh-local-library

- **仓库地址**: https://github.com/Fucaplos/dsh-local-library
- **收录分类**: 其他
- **插件简介**: 本地资料库（仅 Windows，需用随包的 PowerShell 脚本安装）：文件传一次，之后每个对话都能用四个工具（library_list / library_search / library_read / library_save）检索、读取；上传、下载与打包下载在设置页完成。文件只保存在本机——除非你启用可选的视觉模型，它会把图片发到你配置的接口。
