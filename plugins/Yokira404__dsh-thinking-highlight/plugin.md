# Yokira404/dsh-thinking-highlight

- **仓库地址**: https://github.com/Yokira404/dsh-thinking-highlight
- **收录分类**: 其他
- **插件简介**: 统计思考行里的关键词并在展开后按词标红；标题行上每个词一个计数徽章，点徽章即单独开关这个词；每个词可设底色、文字颜色、字号（10-22px，与宿主正文尺寸同一区间）、字体、加粗/斜体/下划线与「完整词」匹配；插件有独立的设置分区。
