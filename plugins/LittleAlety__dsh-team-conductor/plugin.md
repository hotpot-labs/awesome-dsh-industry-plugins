# LittleAlety/dsh-team-conductor

- **仓库地址**: https://github.com/LittleAlety/dsh-team-conductor
- **收录分类**: 其他
- **插件简介**: 内核 Agent Teams 的控制面：团队成员是与 GUI 同一条缝创建的普通独立会话（各自有模型），能像任何对话一样打开与继续；名册与任务板在侧车里协调它们——任务带完成标准，成员完成后提交并等待 Lead 审议，状态区分空闲 / 待审议 / 上一轮失败。delegationEngine=auto 会按组合提供的能力选择独立会话、可续接子代理或内核 roster。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-28
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。
