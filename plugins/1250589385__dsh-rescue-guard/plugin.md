# 1250589385/dsh-rescue-guard

- **仓库地址**: https://github.com/1250589385/dsh-rescue-guard
- **收录分类**: 计算机
- **插件简介**: 在 DSH 打不开时救回配置：不依赖 DSH 的命令行工具，把崩溃日志归类（六类原因，全部来自真实事故），启动前预检命令名冲突与插件构造期读取的文件，布防安全模式（只加载官方 bundle，启动正常后自动还原），并保留清单快照供回滚。另有一个常驻守护进程，用操作系统文件事件盯着崩溃日志目录——空闲零开销，加载器一死几秒内写出自检报告，每次崩溃只覆盖一份文件。仅限 Windows：崩溃日志读自 %APPDATA%，守护进程经 Windows「启动」文件夹自启。
