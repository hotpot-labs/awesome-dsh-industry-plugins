# Elefseus/dsh-default-workspace

- **仓库地址**: https://github.com/Elefseus/dsh-default-workspace
- **收录分类**: 其他
- **插件简介**: 把默认工作区从系统盘挪走（DSH 把新会话一律开在 <文档>/deepseek-harness/default-workspace 且从不迁移），同时让已存会话继续可用：无需重启即可改写工作区记录，同一套动作也有图形面板可点，连同 header cwd 把已存会话日志一起搬走，并重帧化首帧不是恰好一行 header 的日志。需桌面版宿主（workspaceRegistry 与 sessionPersistence）。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-30
- **审核定级**: 🔴 黑名单 (禁止使用)
