# Passenger-Qin/dsh-task-splitter

- **仓库地址**: https://github.com/Passenger-Qin/dsh-task-splitter
- **收录分类**: 其他
- **插件简介**: 面向小上下文本地模型的宿主侧长任务识别：长产出自动拆成分段骨架（每轮只写一段，最后拼装），多步骤任务自动建立 PLAN.md 台账与 notes/（先立计划、每轮执行一步）。判定在宿主侧用启发式完成，不依赖模型自己判断极限。
