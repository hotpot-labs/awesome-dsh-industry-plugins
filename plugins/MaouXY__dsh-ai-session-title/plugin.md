# MaouXY/dsh-ai-session-title

- **仓库地址**: https://github.com/MaouXY/dsh-ai-session-title
- **收录分类**: 其他
- **插件简介**: 用会话自己的模型从对话内容生成会话标题，可走 /ai-title 命令，也可点重命名弹窗里的按钮。提供四种标题结构（主题、动作、主题 + 结论、自定义提示词）和可选的「月-日」前缀，均可在插件设置页调整。

- **审核定级**: 🔴 黑名单 (禁止使用)
