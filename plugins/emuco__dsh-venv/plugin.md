# emuco/dsh-venv

- **仓库地址**: https://github.com/emuco/dsh-venv
- **收录分类**: 其他
- **插件简介**: 为每个 DSH 工作区/项目提供独立的运行时环境：自动接管或创建项目本地 Python venv（.venv_local/python），并自动识别项目所用运行时（python venv / node / go）接入其工具链与环境变量——python / pip 永远走项目环境，绝不静默落到系统 Python。一个有则接管、无则自动建的零配置插件。
