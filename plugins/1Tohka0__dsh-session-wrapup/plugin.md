# 1Tohka0/dsh-session-wrapup

- **仓库地址**: https://github.com/1Tohka0/dsh-session-wrapup
- **收录分类**: 其他
- **插件简介**: 对话收尾：把一次对话产生的文件分成五类列出，勾选删除的文件先进回收站保留 3 天，下次启动时清掉这个会话的日志。它的 HTTP 路由没有 DSH 的访问检查，浏览器里打开的网页可以调用它们。
