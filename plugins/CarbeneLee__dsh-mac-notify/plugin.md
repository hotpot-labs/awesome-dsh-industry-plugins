# CarbeneLee/dsh-mac-notify

- **仓库地址**: https://github.com/CarbeneLee/dsh-mac-notify
- **收录分类**: 其他
- **插件简介**: 为 DSH 提供 macOS 原生通知：任务完成、失败、需要批准、需要回答、计划确认时弹横幅。内置的极简 helper 应用让横幅使用 DSH 图标、点击唤起 DSH；提示音可以用任意音频文件。

- **审核定级**: 🔴 黑名单 (禁止使用)
