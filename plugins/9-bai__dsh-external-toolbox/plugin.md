# 9-bai/dsh-external-toolbox

- **仓库地址**: https://github.com/9-bai/dsh-external-toolbox
- **收录分类**: 其他
- **插件简介**: 在任意 Windows 程序里选中文字，旁边冒出一个小胶囊：翻译、解释、引用到新的 DSH 会话、存入按遗忘曲线复习的生词本，或者直接复制。不用切窗口，浮窗也不抢焦点。
