# Lovepeace-art/dsh-android-phone

- **仓库地址**: https://github.com/Lovepeace-art/dsh-android-phone
- **收录分类**: 其他
- **插件简介**: 在 DSH 侧栏实时显示 USB 连接的安卓手机，并通过 scrcpy 控制协议直接操作手机：12 个 agent 工具（点按/滑动/输入/按键）、多帧滚动拼接的长截图，以及「默认交给 agent、人一碰手机就立刻交出控制权」的控制权模型。自带 adb 与 scrcpy-server。仅 Windows 10/11；侧栏实时镜像还需 dsh-better-sidebar。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-20
