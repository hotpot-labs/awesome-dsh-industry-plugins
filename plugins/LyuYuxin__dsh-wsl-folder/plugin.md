# LyuYuxin/dsh-wsl-folder

- **仓库地址**: https://github.com/LyuYuxin/dsh-wsl-folder
- **收录分类**: 其他
- **插件简介**: 在侧栏的「添加工作区」按钮里把 WSL 目录加成 DSH 工作区：选发行版、浏览目录后以 \\wsl.localhost 路径注册；该工作区的侧栏终端开在发行版里，agent 也能正常写入其中的文件。需 Windows 10/11 并已安装 WSL。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-02
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
