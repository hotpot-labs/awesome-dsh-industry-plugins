# WuJiaoJue/dsh-later

- **仓库地址**: https://github.com/WuJiaoJue/dsh-later
- **收录分类**: 其他
- **插件简介**: 基于 dsh-schedule 引擎的会话内定时消息：输入框定时面板（智能时段/自定义时间）、待发送 dock（逐条取消与行内编辑）、把当前输入稍后以你身份发出的 /later 命令，以及侧栏像素时钟标识；调度在服务端执行，关掉网页也会准时触发。
