# DogEgg-alR/dsh-scan-to-pdf

- **仓库地址**: https://github.com/DogEgg-alR/dsh-scan-to-pdf
- **收录分类**: 其他
- **插件简介**: 在插件页的一个标签里，把拍照 / 扫描的页面抄成排版好的 PDF。图片、ZIP、Word、PDF 都能拖进来（PDF 逐页渲成图片，所以里面的扫描件一样能抄），每页先按扫描件处理：白底合成、拉对比、统一尺寸。视觉模型把每页抄成 Markdown，看到插图时留下占位符和一个 0~1 的包围框，插件按框从页面上裁出这幅图、做同样的清理、再放回正文里的那个位置。版式是真正的 Word 排版再经 LibreOffice 转换：A4、奇偶页页码分居左右、表格只留横线。它的 HTTP 路由没有 DSH 的访问检查，浏览器里打开的网页可以调用它们。
