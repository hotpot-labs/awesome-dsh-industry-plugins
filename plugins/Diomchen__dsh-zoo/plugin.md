# Diomchen/dsh-zoo

- **仓库地址**: https://github.com/Diomchen/dsh-zoo
- **收录分类**: 其他
- **插件简介**: 让同一局域网里的 DSH 宠物互相看见、互相串门，还能捎一张字条或一个文件。桌面宠物需要 macOS 或 Windows 上的 DSH Desktop（Electron）；在 Linux 或 web profile 上，发现和串门仍可用，但没有桌面层。
