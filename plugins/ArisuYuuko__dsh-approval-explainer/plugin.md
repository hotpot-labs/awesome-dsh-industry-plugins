# ArisuYuuko/dsh-approval-explainer

- **仓库地址**: https://github.com/ArisuYuuko/dsh-approval-explainer
- **收录分类**: 其他
- **插件简介**: 为 DSH 的提权审批弹窗加一份由模型生成的注释，说明这段代码做什么、模型想达成什么、风险多大以及原因、每个选项意味着什么，并提供 /dsh-approval/diag 诊断页。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-18
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
