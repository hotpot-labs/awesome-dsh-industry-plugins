# 1250589385/dsh-test-autofix

- **仓库地址**: https://github.com/1250589385/dsh-test-autofix
- **收录分类**: 计算机
- **插件简介**: 提供一个 run_tests 工具，把失败的测试运行变成精确上下文，而不是原始大段输出。自动识别测试框架（pytest、jest、vitest、cargo、go、npm），提取每个失败的 file、line 与断言；同一失败签名反复出现时停止循环。输出经过解码，Windows 编码与非拉丁断言文字都能正常显示。
