# Keridium/dsh-gopeed-downloader

- **仓库地址**: https://github.com/Keridium/dsh-gopeed-downloader
- **收录分类**: 其他
- **插件简介**: 把本机 Gopeed 下载器接进 DSH 的 agent 工具：新建、查看、暂停、继续、删除下载任务，诊断或启动 Gopeed 进程，并通过 DSH 后台任务接收下载完成事件（空闲的 agent 会被唤醒）。进程诊断与启动仅支持 Windows，下载相关工具跨平台可用。
