# Fishexploi/dsh-mesh

- **仓库地址**: https://github.com/Fishexploi/dsh-mesh
- **收录分类**: 其他
- **插件简介**: 局域网内的 DSH 多机任务委派：上级把任务派给子级主机，子级在自己的会话与工作区里执行，结果与文件回到上级收件箱，敏感动作等待上级审批，完成的任务还能在子级原会话里接着追问一轮。默认每台主机会在自己的端口上监听全部网卡（0.0.0.0），走明文 HTTP，并用 UDP 做发现；配对用六位数字码，没有尝试次数限制，配对后的上级默认没有任何授权。
