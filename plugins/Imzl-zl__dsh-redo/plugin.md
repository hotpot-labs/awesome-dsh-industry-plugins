# Imzl-zl/dsh-redo

- **仓库地址**: https://github.com/Imzl-zl/dsh-redo
- **收录分类**: 其他
- **插件简介**: 给你发出的每条消息加上「重新生成」和「编辑重发」：重新生成一键用同样的文字重新回答，不经过输入框；编辑重发就地撤回这条消息及其之后的内容——从时间线和模型上下文里一起消失，不新建会话也不开新分支——再把文字和图片放回输入框，改完发送就从那一条重写对话。带文件（非图片）的消息两个操作置灰。
