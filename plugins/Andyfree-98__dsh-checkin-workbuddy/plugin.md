# Andyfree-98/dsh-checkin-workbuddy

- **仓库地址**: https://github.com/Andyfree-98/dsh-checkin-workbuddy
- **收录分类**: 其他
- **插件简介**: 常驻输入框工具行的 WorkBuddy 每日签到按钮，一键调用 dsh-connect-workbuddy 的签到路由为当前选中账号签到，并在按钮旁显示结果：已签到、签到成功加分或连签天数。已签状态通过本地日期戳跨会话保留，加载时与上游状态对账，跨天后自动复位。
