# CoraxEldridge/dsh-managed-workspaces

- **仓库地址**: https://github.com/CoraxEldridge/dsh-managed-workspaces
- **收录分类**: 其他
- **插件简介**: 在可配置的根目录下创建 DSH 工作区，把多个外部文件夹关联到同一个工作区，并能在不丢失对话的情况下迁移工作区。它的 managed_workspace 工具允许模型创建、接管、关联、迁移和注销工作区（迁移会移动整个文件夹，有会话时在原路径留一个链接），插件的 HTTP 路由（/dsh-managed-workspaces/api/…）除一个标记头外没有 DSH 的访问检查。
