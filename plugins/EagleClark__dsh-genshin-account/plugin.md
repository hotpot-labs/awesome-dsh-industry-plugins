# EagleClark/dsh-genshin-account

- **仓库地址**: https://github.com/EagleClark/dsh-genshin-account
- **收录分类**: 其他
- **插件简介**: 把原神账号读成一份快照（角色、天赋、武器、圣遗物、祈愿记录），对外给 6 个 agent 工具和一个六页签面板。圣遗物副词条取自游戏内公开的角色展柜；评分同时给 CV 与逐角色权重两套模型，各六档评级；抽卡分析包含保底、欧非分档与各池进度。读取角色、武器与祈愿需要米游社扫码登录；展柜数据按 UID 公开。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-27
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。
