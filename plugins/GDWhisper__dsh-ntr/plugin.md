# GDWhisper/dsh-ntr

- **仓库地址**: https://github.com/GDWhisper/dsh-ntr
- **收录分类**: 其他
- **插件简介**: 让一条 DSH 会话由任意 ACP agent 通过 stdio 服务：agent、模型、思考等级与权限模式全部由 agent 自己提供，工具调用流入主聊天区，diff 汇总在单独的 NTR 页，权限询问出现在输入框里。需先在本机安装一个支持 ACP 的 agent 命令行。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-27
- **审核定级**: 🔴 黑名单 (禁止使用)
