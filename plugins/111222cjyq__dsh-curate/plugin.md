# 111222cjyq/dsh-curate

- **仓库地址**: https://github.com/111222cjyq/dsh-curate
- **收录分类**: 其他
- **插件简介**: 面向 DSH 会话的人工上下文整理工作台：可为整轮或单条消息标记「重要（原文保留）／一般／次要」，不调用模型即可改写用户、助手、工具结果与注入上下文消息，再按标记区间用模型生成的摘要压缩，或调用官方 /compact（范围由官方压缩器决定）；每次写入前都会生成一份本地 JSON 备份。
