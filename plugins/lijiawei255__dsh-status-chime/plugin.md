# lijiawei255/dsh-status-chime

- **仓库地址**: https://github.com/lijiawei255/dsh-status-chime
- **收录分类**: 其他
- **插件简介**: DSH 状态变化时读出一句简短提示——本轮完成、本轮出错、后台任务结束、后台任务失败、目标完成、目标受阻、等待批准、等待你回答——中文（默认）与英文各八条预录语音。音频由宿主进程播放（ffplay，或系统自带的 Windows PowerShell 播放器），不依赖浏览器 Web Audio。仅支持 Windows。
