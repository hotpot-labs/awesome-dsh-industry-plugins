# better-er/dsh-remote-file-system

- **仓库地址**: https://github.com/better-er/dsh-remote-file-system
- **收录分类**: 其他
- **插件简介**: 模型可直接调用的 ssh 远程文件三件套：read_remote 按行号分页读远端 UTF-8 文本，write_remote 只新建文件、目标已存在即拒绝且没有覆写分支，edit_remote 做唯一匹配的字面替换，三者共用取自 ~/.ssh/config 的「别名:路径」一个 file_path 字段。

- **审核定级**: 🔴 黑名单 (禁止使用)
