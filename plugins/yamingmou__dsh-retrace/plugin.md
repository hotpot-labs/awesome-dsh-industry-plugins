# yamingmou/dsh-retrace

- **仓库地址**: https://github.com/yamingmou/dsh-retrace
- **收录分类**: 其他
- **插件简介**: 撤回/编辑重发/重新生成，加上单会话版本化：每次回退的时间线、产物回退（git 优先、快照兜底）、分叉图、会话谱系，以及实时看门狗（并发写入第一时间快照日志）。编辑前自动停止运行中的 agent（官方 cancel/whenIdle），回退不会损坏持久化日志、也不会破坏 /compact。
