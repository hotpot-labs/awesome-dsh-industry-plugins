# KarlOfLaw/dsh-side-chat

- **仓库地址**: https://github.com/KarlOfLaw/dsh-side-chat
- **收录分类**: 其他

- **审核日期**: 2026-08-25
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。
