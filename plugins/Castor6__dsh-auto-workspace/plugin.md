# Castor6/dsh-auto-workspace

- **仓库地址**: https://github.com/Castor6/dsh-auto-workspace
- **收录分类**: 其他
- **插件简介**: 为 dsh 提供无项目聊天：不选工作区创建的会话会获得自己的目录（~/Documents/DSH/<日期>/chat-NN），重新打开会话时复用，并留在「未分组」而不会变成侧栏项目；新建会话的 Hero 上新增悬浮清除徽标与「不在工作区中工作」一行，另有一个仅存在于浏览器端的哨兵工作区，让该 Hero 及其输入框保持可用。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-17
- **审核定级**: 🔴 黑名单 (禁止使用)
