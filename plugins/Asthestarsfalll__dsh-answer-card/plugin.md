# Asthestarsfalll/dsh-answer-card

- **仓库地址**: https://github.com/Asthestarsfalll/dsh-answer-card
- **收录分类**: 其他
- **插件简介**: macOS 悬浮卡片：审批、提问、回合结束三种时刻弹卡，点选项即等于在 DSH 里作答；完成卡可跨桌面、跨 workspace 回到会话，并把光标和鼠标指针放回输入框。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-25
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
