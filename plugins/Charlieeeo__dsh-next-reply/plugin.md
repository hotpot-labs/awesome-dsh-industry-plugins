# Charlieeeo/dsh-next-reply

- **仓库地址**: https://github.com/Charlieeeo/dsh-next-reply
- **收录分类**: 其他
- **插件简介**: 每条回答结束后，在本轮下方显示最多 3 条竖排的下一步建议：建议由主回复自身给出，不额外调用模型。点建议文字会插入输入框光标处；纸飞机按钮直接发送，气泡按钮插入输入框。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-28
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
