# Chang-Tong/dsh-unified-context

- **仓库地址**: https://github.com/Chang-Tong/dsh-unified-context
- **收录分类**: 其他
- **插件简介**: 把 pi、opencode、codex、claude-code 与 WorkBuddy 的会话导入 DSH，用符号链接在各 Harness 间共享同一份 AGENTS.md、技能、项目与 Agent 记忆，并把 Codex / WorkBuddy 自动化迁移为 DSH 定时任务。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-10
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
