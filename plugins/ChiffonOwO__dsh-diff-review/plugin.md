# ChiffonOwO/dsh-diff-review

- **仓库地址**: https://github.com/ChiffonOwO/dsh-diff-review
- **收录分类**: 其他
- **插件简介**: 本轮改动审查：输入框上方的气泡统计本回合改动文件数与行数，悬停时向上浮出文件清单；右侧边栏按标签页展示逐文件语法高亮 diff，并支持一键还原。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-25
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
