# 7gzgn/dsh-inpage-translator

- **仓库地址**: https://github.com/7gzgn/dsh-inpage-translator
- **收录分类**: 其他
- **插件简介**: 给内置浏览器的每一张页面常驻一个「🈯 译」按钮：点一下，页面上每个可见文本节点原地换成译文；再点一下回到原文。长按可拖动，拖到左右边缘自动吸成贴边小把手；页面导航后自动重装。翻译走宿主模型服务 —— 插件不持有任何 API key。
