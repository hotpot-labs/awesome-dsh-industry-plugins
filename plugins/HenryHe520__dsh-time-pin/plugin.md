# HenryHe520/dsh-time-pin

- **仓库地址**: https://github.com/HenryHe520/dsh-time-pin
- **收录分类**: 其他
- **插件简介**: 为单个对话钉住 as_of 时间点与前后两侧的带日期证据窗口——[as_of − before, as_of + after]，支持过去、未来与公元前。在受限模式下，窗口变化时只告知一次当前窗口，web_search 结果按发布日期过滤到窗口内、无日期来源一律排除，首条回复必须确认窗口（缺失时纠正一次）。另对长时间静默的后台任务给出确定性 [TIME FACT] 播报，并提供只读的 time_pin_status 工具；默认模式不注入、不过滤。
