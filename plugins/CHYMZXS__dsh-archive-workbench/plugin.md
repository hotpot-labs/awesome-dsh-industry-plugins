# CHYMZXS/dsh-archive-workbench

- **仓库地址**: https://github.com/CHYMZXS/dsh-archive-workbench
- **收录分类**: 其他
- **插件简介**: 在侧边栏会话行菜单中新增「删除会话」，永久清除该会话的日志目录、投影缓存与归档/置顶记录，并让该行从侧边栏消失；同时在侧边栏提供已归档会话面板，可恢复或删除已归档会话。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-21
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
