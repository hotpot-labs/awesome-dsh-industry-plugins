# Chenfan2/dsh-bilibili-subtitles

- **仓库地址**: https://github.com/Chenfan2/dsh-bilibili-subtitles
- **收录分类**: 其他
- **插件简介**: 从 Bilibili 视频或本地视频提取字幕，输出 Markdown、Word、PDF、TXT、SRT 或 JSON，支持时间戳、双语对齐和质量报告。需 Python 3.10+；平台/AI 字幕需 Bilibili SESSDATA Cookie；OCR/ASR/PDF 需 ffmpeg、faster-whisper，以及 LibreOffice 或 reportlab。
