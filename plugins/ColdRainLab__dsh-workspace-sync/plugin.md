# ColdRainLab/dsh-workspace-sync

- **仓库地址**: https://github.com/ColdRainLab/dsh-workspace-sync
- **收录分类**: 其他
- **插件简介**: 把工作区、会话记录与自动化任务同步到你自己的云端目录（网盘同步文件夹，后端可扩展），换机器登录后拉取即见。云端目录里是明文会话日志；被 dsh-workspace-vault 隐藏或加锁的工作区不会上传。
