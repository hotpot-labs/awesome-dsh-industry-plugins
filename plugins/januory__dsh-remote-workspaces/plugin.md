# januory/dsh-remote-workspaces

- **仓库地址**: https://github.com/januory/dsh-remote-workspaces
- **收录分类**: 其他
- **插件简介**: 通过 SSH 把远程主机目录作为 Harness 工作区打开：read/write/edit/grep/glob 与 shell 命令经 SFTP、ripgrep、ssh2 exec 直接在远程主机执行，不做本地镜像；多主机注册表加密存储，本地沙箱策略依然生效。
