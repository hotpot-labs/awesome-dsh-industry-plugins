# HildebrandYu/dsh-open-with

- **仓库地址**: https://github.com/HildebrandYu/dsh-open-with
- **收录分类**: 其他
- **插件简介**: 讓 DSH 擁有自己的「副檔名 → 開啟 app」規則：卡片、側邊預覽與變更審查用你指定的 app 開啟， 而 macOS 的 Finder 雙擊預設不受影響。規則在設定頁編輯、存於 ~/.dsh/open-with.json； 「顯示文件位置」仍走 Finder。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-10-20
- **审核定级**: 🔴 黑名单 (禁止使用)
