# Archaofan/dsh-notify-relay

- **仓库地址**: https://github.com/Archaofan/dsh-notify-relay
- **收录分类**: 其他
- **插件简介**: 把 DSH 的八类生命周期事件过去重、免打扰、摘要合批三道关后外发到七个通道。严重度映射到 Bark、ntfy、Telegram 和 webhook 真正支持的字段；失败投递带抖动退避重试并可跨重启恢复；单通道熔断避免反复敲一个已死的地址；自检发现中继降级时主动报告而不是静默。
