# john-walks-slow/dsh-message-datetime

- **仓库地址**: https://github.com/john-walks-slow/dsh-message-datetime
- **收录分类**: 其他
- **插件简介**: 每轮对话开始向模型上下文注入单行时间戳读数（星期 / 日期 / 时间 / UTC 偏移 / IANA 时区），收尾再注入 Turn ended 关闭读数——模型始终知道现在几点、今天星期几、上一轮何时结束，日期运算与跨轮间隔不再靠猜；轻量时钟感知，每条约 30 token。
