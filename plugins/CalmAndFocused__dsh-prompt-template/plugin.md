# CalmAndFocused/dsh-prompt-template

- **仓库地址**: https://github.com/CalmAndFocused/dsh-prompt-template
- **收录分类**: 其他
- **插件简介**: 在输入框里用三种模式改写提示词草稿（系统提示词、用户提示词、迭代改进），{{变量}} 占位符逐字保留，同一操作也作为 optimize_prompt agent 工具提供。
- **收录来源**: awesome-dsh-plugin
- **审核日期**: 2026-11-16
- **审核定级**: 🔴 黑名单 (禁止使用)

完整审核报告见同目录 [security-report.md](./security-report.md)。

> ⚠️ 自动审核不等于人工审计，报告中标注「需人工复核」的检查项以人工复核结论为准。
