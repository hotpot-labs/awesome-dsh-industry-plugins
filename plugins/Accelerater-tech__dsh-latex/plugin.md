# Accelerater-tech/dsh-latex

- **仓库地址**: https://github.com/Accelerater-tech/dsh-latex
- **收录分类**: 其他
- **插件简介**: 用本机已装的 TeX Live 真编译 LaTeX：`latex` 工具把一个公式排成 SVG、PNG 或 PDF，把整份文档排成 PDF（正文含中文时自动切 xelatex + ctexart），产物写进工作区并返回可直接引用的 Markdown 链接。同时注入系统提示词段落，让模型用 `$...$` / `$$...$$` 而不是代码块写公式；本机没有 TeX Live 时，输入框上方会给出 BasicTeX / TinyTeX 一键安装。
