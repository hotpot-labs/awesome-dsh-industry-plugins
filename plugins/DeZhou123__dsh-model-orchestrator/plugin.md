# DeZhou123/dsh-model-orchestrator

- **仓库地址**: https://github.com/DeZhou123/dsh-model-orchestrator
- **收录分类**: 其他
- **插件简介**: 两级模型调度：先在模型层选最优模型组，再在该模型的渠道层选最佳渠道；失败时先换同模型的其它渠道，整个模型不可用才换模型。偏好模式把单个模型锁在它的各条渠道上，输入框下方的状态条实时显示当前模型、渠道健康与今日 token 用量，并可从测速/智力报告导入路由先验；另提供 model_orchestrator 工具与 /route 命令。
- **收录来源**: awesome-dsh-plugin
