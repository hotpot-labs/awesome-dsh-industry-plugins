# Chriszzx/dsh-bookshelf

- **仓库地址**: https://github.com/Chriszzx/dsh-bookshelf
- **收录分类**: 其他
- **插件简介**: 在 DeepSeek Harness 中管理和阅读本地 PDF、EPUB，保存阅读进度与书签，并将 EPUB 当前页带入会话讨论。它的 HTTP 路由没有 DSH 的访问检查，浏览器里打开的网页可以调用它们。
