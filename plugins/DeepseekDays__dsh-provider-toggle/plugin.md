# DeepseekDays/dsh-provider-toggle

- **仓库地址**: https://github.com/DeepseekDays/dsh-provider-toggle
- **收录分类**: 其他
- **插件简介**: 在「设置 → 模型」每个提供商行的「编辑」左边加一个一键开关：关掉哪个提供商，它就从主界面模型选择栏里消失，打开即恢复。做法是包一层模型目录调用，因此只影响目录与选择器，不动路由、密钥与 provider 配置；已经选着该模型的旧会话照常工作。
