# Dubai1210/dsh-session-delete

- **仓库地址**: https://github.com/Dubai1210/dsh-session-delete
- **收录分类**: 其他
- **插件简介**: 在会话菜单里删除 DSH 会话，并列出该会话碰过的工作区文件，由你勾选哪些一起删掉。删除是永久的、无法撤销；通过 shell 命令写出的文件不在追踪范围内。

- **审核日期**: 2026-11-11
- **审核定级**: 🔴 黑名单 (禁止使用)
