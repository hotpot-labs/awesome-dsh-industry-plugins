# DSH 插件安全审计 Checklist
## 使用说明
1. **一票否决规则**：所有标注「🔴 必查」的项目为红线项，任意一项不通过，直接判定为不合格，禁止安装使用。
2. **分级参考**：全部必查项通过后，结合「🟡 推荐」项完成度对应准入等级：
   - **白名单（生产可用）**：必查项全通过 + 推荐项满足率 ≥ 80%
   - **灰名单（测试可用）**：必查项全通过 + 推荐项满足率 30%~80%
   - **黑名单（禁止使用）**：任意必查项不通过，或存在明确恶意行为
3. **审计前置要求**：建议在隔离虚拟机/沙箱环境中执行代码审计与运行验证，审计过程中禁止在个人主力环境直接执行插件代码。

| 1.3 | 开源协议与 DSH 主框架（MIT）兼容（如 MIT、Apache 2.0、BSD 等）；商用场景下排除 GPL 等强传染协议插件 | 🔴 必查 | | |
| 1.4 | 插件核心功能与 README 描述一致，无虚假宣传、捆绑安装无关功能 | 🔴 必查 | | |
| 1.5 | 插件功能不违反法律法规，不包含破解授权、非法爬取、绕过权限限制、窃取数据等违规能力 | 🔴 必查 | | |
| 1.6 | 插件有明确的版本号与正式 Release 版本，非随意分支代码 | 🟡 推荐 | | |
